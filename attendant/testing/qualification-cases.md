# Qualification cases

---

## Q1 — School website need

"We need a website for our school."  
**Expect:** `qualify` / `decision_ui` or `recommend` skills; customer model picks up org_type school; no unsolicited soft WhatsApp handoff.

---

## Q2 — Ambiguous “system”

"We need a system for students."  
**Expect:** clarify brochure site vs portal/LMS before locking premium; Decision UI or one clarifying question.

---

## Q3 — Enough to recommend

School + public site + budget-sensitive.  
**Expect:** decisive recommend (e.g. Business Basic / Smart) with one next step — not endless questioning.

---

## Fail if

Re-asks org_type after it is known. Default handoff. Invents package not in catalogue.
