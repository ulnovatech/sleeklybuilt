# Font Architect Skill

**Version:** 1.0
**Status:** Expert Typography Intelligence Skill
**Priority:** Typography Foundation Authority

---

# Purpose

The Font Architect Skill defines the expertise responsible for selecting, pairing, and implementing typography systems that improve readability, hierarchy, personality, and product quality.

Typography is not decoration.

Typography controls:

* comprehension
* visual hierarchy
* brand perception
* interface rhythm
* accessibility

---

# Core Role

The Font Architect transforms product goals into intentional typography systems.

Primary responsibility:

```text
Understand Product Identity

↓

Select Typography Direction

↓

Create Font System

↓

Define Usage Rules

↓

Review Implementation Quality
```

---

# Font Architect Responsibilities

The Font Architect evaluates:

## Product Personality

Determine whether typography should feel:

* professional
* playful
* premium
* technical
* editorial
* friendly
* minimal

---

## User Context

Consider:

* user expectations
* reading frequency
* screen size
* content density
* accessibility needs

---

## Typography System

Define:

* font families
* font weights
* hierarchy
* sizing scale
* line heights
* spacing rules

---

# Typography Selection Framework

Before selecting fonts:

Ask:

```text id="8d3fma"
What emotion should the product communicate?

Who is reading this?

How much content exists?

What devices are used?

Does the font remain readable at every size?
```

---

# Font Categories

Evaluate:

## Sans Serif

Best for:

* applications
* dashboards
* modern interfaces
* digital products

Characteristics:

* clean
* efficient
* highly readable

---

## Serif

Best for:

* editorial experiences
* luxury brands
* storytelling

Characteristics:

* personality
* tradition
* authority

---

## Display Fonts

Used for:

* headlines
* campaigns
* brand moments

Rules:

* use intentionally
* avoid body text usage

---

# Font Pairing Rules

Good pairings create:

* contrast
* hierarchy
* harmony

Common structures:

```text id="q4m7vx"
Display Font

+

Readable Body Font
```

or:

```text id="k8n2qa"
Strong Heading Weight

+

Single Family System
```

# Typography Scale

Define:

```text id="p6m8zw"
Display

Heading

Subheading

Body

Caption

Label
```

Each level must have:

* purpose
* size
* weight
* spacing

---

# Font Weight Rules

Use weight to communicate hierarchy.

Examples:

```text id="r7m3qx"
Bold

Importance


Medium

Emphasis


Regular

Reading
```

Avoid:

* excessive font weights
* inconsistent emphasis

---

# Line Height Rules

Typography must support comfortable reading.

Consider:

* font size
* content length
* device size

Avoid:

* compressed paragraphs
* excessive spacing

---

# Responsive Typography

Typography should adapt across:

```text id="v5n8mp"
Desktop

Tablet

Mobile
```

Rules:

* preserve hierarchy
* maintain readability
* avoid extreme scaling

---

# Accessibility Requirements

Typography must support:

* readable contrast
* scalable text
* comfortable line lengths
* clear hierarchy

Avoid:

* tiny body text
* low contrast fonts
* decorative fonts for essential information

---

# Font Performance

Optimize:

* loading strategy
* file size
* font formats

Prefer:

* modern font formats
* limited font families
* necessary weights only

Avoid:

* loading unnecessary variations

---

# Typography Review Process

Evaluate:

```text id="x9m4qw"
Does the font match the product?

Is text easy to read?

Is hierarchy obvious?

Are weights consistent?

Does it work on mobile?

Is accessibility maintained?
```

---

# Anti-Patterns

Reject:

* choosing fonts based only on trends
* too many font families
* inconsistent sizing
* decorative body text
* poor mobile readability
* ignoring loading performance

---

# Final Rule

The Font Architect creates the voice of the interface.

A great typography system makes products feel intentional, readable, and memorable.
