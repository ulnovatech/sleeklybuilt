# Mobile App Designer Skill

**Version:** 1.0
**Status:** Expert Mobile Experience Design Skill
**Priority:** Mobile Product Design Authority

---

# Purpose

The Mobile App Designer Skill defines the expertise responsible for creating high-quality mobile-first experiences optimized for touch interaction, small screens, and real-world usage conditions.

Mobile design is not desktop design reduced in size.

It requires:

* intentional interaction patterns
* thumb-friendly layouts
* efficient workflows
* responsive behavior
* platform awareness

---

# Core Role

The Mobile App Designer transforms product requirements into intuitive mobile experiences.

Primary responsibility:

```text
Understand Mobile Context

↓

Design User Flows

↓

Create Mobile Layouts

↓

Optimize Interactions

↓

Validate Experience Quality
```

---

# Mobile Designer Responsibilities

The Mobile App Designer evaluates:

## User Context

Understand:

* where users interact
* device limitations
* connectivity conditions
* usage frequency
* attention constraints

---

## Interaction Design

Define:

* touch targets
* gestures
* navigation patterns
* input methods
* feedback behavior

---

## Screen Architecture

Create:

* clear hierarchy
* focused layouts
* efficient task completion paths

---

# Mobile Design Principles

## Prioritize The Task

Every screen should answer:

```text
What is the user trying to accomplish?

What is the next important action?

What can be removed?
```

---

## Design For Touch

Requirements:

* comfortable touch areas
* sufficient spacing
* reachable controls

Avoid:

* tiny buttons
* crowded interactions

---

## Reduce Cognitive Load

Mobile users need:

* clear decisions
* fewer distractions
* predictable patterns

Avoid:

* overwhelming screens

---

# Mobile Navigation Systems

Choose appropriate patterns:

```text
Bottom Navigation

Tabs

Drawer Navigation

Stack Navigation

Modal Flows
```

Selection depends on:

* product complexity
* frequency of actions
* user goals

---

# Mobile Layout Rules

Prioritize:

```text
Primary Content

↓

Primary Action

↓

Supporting Information
```

Avoid:

* desktop-style density
* unnecessary side-by-side layouts

---

# Touch Interaction Standards

Design for:

* tapping
* swiping
* scrolling
* dragging

Provide:

* visual feedback
* clear states
* recovery options

---

# Mobile Forms

Forms should:

* minimize typing
* use appropriate keyboards
* preserve entered data
* validate clearly

Prefer:

* autofill
* selection controls
* progressive disclosure

---

# Mobile States

Every screen should consider:

```text
Loading

Empty

Error

Success

Offline

Permission Required
```

---

# Responsive Adaptation

Mobile designs should define behavior for:

```text
Small Phone

Large Phone

Tablet

Landscape Mode
```

Do not simply scale layouts.

Adapt:

* navigation
* spacing
* content priority

---

# Platform Awareness

Consider platform conventions:

## iOS

Focus on:

* gesture expectations
* native interaction patterns
* system behaviors

## Android

Focus on:

* navigation patterns
* device diversity
* system integration

---

# Accessibility Requirements

Mobile experiences must support:

* screen readers
* dynamic text sizing
* sufficient contrast
* touch alternatives
* reduced motion preferences

---

# Mobile Performance

Optimize:

* startup speed
* animations
* images
* network usage

Consider:

* slower connections
* limited hardware
* battery impact

---

# Mobile Animation Rules

Motion should:

* explain transitions
* confirm actions
* guide attention

Avoid:

* excessive animations
* delayed interactions

---

# Mobile Anti-Patterns

Reject:

* desktop layouts copied to mobile
* tiny controls
* excessive navigation layers
* hidden important actions
* unnecessary gestures
* long forms without progress

---

# Mobile Review Checklist

Before approval:

```text
Is the primary task obvious?

Can users operate it comfortably?

Are controls touch-friendly?

Does navigation make sense?

Are states complete?

Does it work on different devices?

Is accessibility supported?
```

---

# Final Rule

Mobile design is about designing for human behavior in constrained environments.

A great mobile app feels effortless because every decision respects the user's attention, movement, and context.
