# Landing Page Designer Skill

**Version:** 1.0
**Status:** Expert Conversion Design Skill
**Priority:** Landing Experience Authority

---

# Purpose

The Landing Page Designer Skill defines the expertise responsible for creating persuasive, high-performing landing experiences that communicate value, establish trust, and guide visitors toward meaningful actions.

A landing page is not a collection of sections.

It is a structured communication system.

---

# Core Role

The Landing Page Designer transforms business goals into clear conversion journeys.

Primary responsibility:

```text
Understand Audience Intent

↓

Define Message Strategy

↓

Structure Page Flow

↓

Design Conversion Experience

↓

Optimize Clarity And Trust
```

---

# Landing Page Designer Responsibilities

The Landing Page Designer evaluates:

## Audience Understanding

Determine:

* who the visitor is
* what problem they have
* what they already know
* what objections exist
* what action they should take

---

## Message Architecture

Define:

* primary message
* supporting arguments
* proof points
* conversion path

Every section must contribute to the visitor's decision.

---

# Landing Page Framework

Before designing:

Ask:

```text
Who is this page for?

What problem does it solve?

Why should visitors care?

Why should they trust this?

What action should they take?
```

---

# Landing Page Structure

A typical structure:

```text
Hero

↓

Problem / Opportunity

↓

Solution

↓

Benefits

↓

Features

↓

Proof

↓

Process

↓

Objections

↓

Call To Action
```

---

# Hero Design

The hero must communicate immediately:

```text
What is this?

Who is it for?

Why does it matter?

What should I do next?
```

---

# Hero Components

May include:

```text
Headline

Supporting Copy

Primary CTA

Secondary CTA

Product Visual

Trust Signal
```

---

# Headline Rules

Strong headlines:

* communicate outcomes
* address user needs
* create clarity

Avoid:

* vague slogans
* empty marketing language

---

# Visual Strategy

Landing page visuals should:

* explain the product
* demonstrate value
* support the message

Use:

* product screenshots
* demonstrations
* illustrations
* meaningful graphics

Avoid:

* decorative visuals without purpose

---

# Section Design

Each section should answer one question.

Examples:

```text
Why does this matter?

How does it work?

Why should I trust it?

What happens next?
```

---

# Benefits Over Features

The designer prioritizes outcomes.

Weak:

```text
AI-powered automation system
```

Strong:

```text
Reduce repetitive work and complete tasks faster
```

---

# Trust System

Trust can include:

```text
Testimonials

Case Studies

Client Results

Reviews

Security Information

Demonstrations
```

Trust elements must feel authentic.

---

# CTA Design

Calls to action should:

* match user readiness
* communicate value
* appear naturally

Examples:

```text
Start Building

Request Demo

Book Consultation

Explore Platform
```

Avoid:

* unclear actions
* excessive competing CTAs

---

# Conversion Psychology

Consider:

* visitor awareness level
* objections
* risk perception
* decision complexity

The page should move users from:

```text
Curiosity

↓

Understanding

↓

Confidence

↓

Action
```

---

# Responsive Landing Design

Desktop:

* rich storytelling
* wider layouts
* stronger visuals

Mobile:

* focused messaging
* simplified sections
* clear CTA placement

Avoid:

* desktop layouts compressed onto mobile

---

# Accessibility Requirements

Landing pages must support:

* semantic structure
* readable typography
* keyboard navigation
* image alternatives
* sufficient contrast

---

# Performance Requirements

Optimize:

* images
* fonts
* animations
* scripts

A beautiful page that loads slowly fails.

---

# Animation Rules

Motion should:

* guide attention
* explain interactions
* improve comprehension

Avoid:

* distracting effects
* animation without purpose

---

# Landing Page Anti-Patterns

Reject:

* unclear value proposition
* feature dumping
* excessive sections
* weak CTA hierarchy
* fake trust signals
* unnecessary animations
* poor mobile experience

---

# Review Checklist

Before approval:

```text
Is the message clear immediately?

Does every section have a purpose?

Is trust established?

Is the CTA obvious?

Does the page work on mobile?

Is accessibility supported?

Does the page encourage action?
```

---

# Final Rule

The Landing Page Designer creates the bridge between attention and action.

A great landing page does not simply look impressive.

It helps visitors understand, trust, and confidently take the next step.
