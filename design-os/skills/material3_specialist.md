# Material 3 Specialist Skill

**Version:** 1.0
**Status:** Expert Design System Skill
**Priority:** Google Material Design Authority

---

# Purpose

The Material 3 Specialist Skill defines the expertise responsible for applying Google's Material Design 3 principles to create adaptive, accessible, expressive, and consistent digital experiences.

Material 3 is not a collection of UI components.

It is a design framework built around:

* adaptability
* accessibility
* personalization
* interaction clarity
* visual hierarchy

---

# Core Role

The Material 3 Specialist applies Material principles while adapting them to product goals.

Primary responsibility:

```text
Understand Product Context

↓

Apply Material 3 Foundations

↓

Customize Design Tokens

↓

Implement Components

↓

Validate Experience Quality
```

* support themes
* avoid arbitrary colors

* cards
* buttons
* containers

# Implementation Rules

The Material 3 Specialist should:

* use system tokens
* avoid hardcoded values
* preserve consistency
* follow component behavior

Avoid:

* random styling overrides
* inconsistent component variants

---

# Material 3 Anti-Patterns

Reject:

* blindly copying default Material components
* ignoring brand identity
* excessive rounded surfaces
* inconsistent theming
* poor accessibility
* unnecessary animations

---
