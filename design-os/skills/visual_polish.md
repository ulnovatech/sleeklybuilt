# Visual Polish Skill

**Version:** 1.0
**Status:** Expert Visual Quality Skill
**Priority:** Final Interface Refinement Authority

---

# Purpose

The Visual Polish Skill defines the expertise responsible for transforming functional interfaces into refined, professional, and visually cohesive experiences.

Visual polish is the final layer that separates:

* acceptable products
* memorable products

It improves:

* consistency
* hierarchy
* perceived quality
* emotional impact

---

# Core Role

The Visual Polish Specialist refines interfaces after structure and functionality are established.

Primary responsibility:

```text id="c5y8mw"
Review Existing Design

↓

Identify Visual Weaknesses

↓

Refine Details

↓

Improve Consistency

↓

Deliver Premium Quality
```

---

# Core Principle

Polish never replaces good design.

The order is:

```text id="9t2mkv"
Function

↓

Structure

↓

Usability

↓

Consistency

↓

Polish
```

# Visual Polish Responsibilities

The specialist evaluates:

## Alignment

Check:

* spacing consistency
* element relationships
* visual rhythm

Avoid:

* accidental misalignment
* inconsistent margins

---

## Typography Refinement

Review:

* font hierarchy
* weight usage
* line spacing
* text density

Improve:

* readability
* emphasis
* scanning

---

## Color Refinement

Evaluate:

* contrast
* balance
* emotional tone
* semantic usage

Avoid:

* random colors
* unnecessary gradients
* inconsistent states

---

## Spacing Refinement

Maintain:

* consistent spacing scale
* breathing room
* component rhythm

Avoid:

* cramped layouts
* excessive empty space

---

# Visual Hierarchy Review

Every screen should communicate:

```text id="x6p3za"

What is secondary?

What action comes next?
```

Hierarchy can be improved through:

* size
* position
* contrast
* spacing
* weight

# Visual Polish Anti-Patterns

Reject:

* adding decoration without purpose
* excessive effects
* inconsistent spacing
* random typography choices
* unnecessary gradients
* over-designed interfaces

---

# Review Checklist

Before approval:

```text id="w2c7qa"
Does every element feel intentional?

Is spacing consistent?

Is hierarchy obvious?

Are components visually unified?

Do interactions feel refined?

Does the product feel premium?
```

---

# Final Rule

Visual polish is the discipline of caring about every detail.

A great interface does not look polished because it has more decoration.

It looks polished because every decision feels deliberate.
