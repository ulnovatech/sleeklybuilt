# Landing Page Design Prompt

**Version:** 1.0
**Status:** Production Marketing Experience Design Prompt
**Priority:** Conversion-Focused Experience Authority

---

# Purpose

This prompt defines the process for designing high-quality landing pages using the Design OS framework.

A landing page is not a decorative webpage.

It is a focused experience designed to:

* communicate value
* build trust
* guide decisions
* drive meaningful action

---

# Design Mission

When creating a landing page:

```text id="w7m4qx"
Understand Audience

↓

Define Value Proposition

↓

Create Narrative Structure

↓

Design Visual Experience

↓

Optimize Conversion Flow

↓

Validate User Confidence
```

---

# Before Designing

Analyze:

## Audience

Determine:

* who is visiting
* what problem they have
* what they need to understand
* what objections exist

---

## Business Goal

Define the primary outcome:

Examples:

* purchase
* signup
* inquiry
* booking
* download
* demonstration request

Avoid:

* multiple competing primary actions

---

# Landing Page Principles

## Clarity Before Creativity

Visitors should quickly understand:

```text id="p4n8vx"
What is this?

Who is it for?

Why should I care?

What should I do next?
```

---

# Hero Section Design

The hero must communicate:

## Value Proposition

Clearly explain:

* product/service
* benefit
* differentiation

---

## Supporting Message

Provide:

* context
* credibility
* explanation

---

## Primary Action

The CTA should be:

* visible
* specific
* easy to understand

Avoid:

* vague actions

Weak:

```text id="m6q2qa"
Learn More
```

Better:

```text id="x8v5nz"
Start Your Free Trial
```

---

# Landing Page Structure

Recommended flow:

```text id="q9m4wp"
Hero

↓

Problem

↓

Solution

↓

Benefits

↓

Features

↓

Proof

↓

Process

↓

FAQ

↓

Final CTA
```

---

# Content Hierarchy

Every section should answer:

```text id="c5p8mv"
Why does this matter?

How does it work?

Why should I trust it?

What happens next?
```

---

# Visual Design Requirements

Apply:

* design tokens
* typography hierarchy
* spacing system
* color system
* imagery strategy
* motion principles

Maintain:

* brand personality
* readability
* focus

---

# Trust Building

Include appropriate trust signals:

Examples:

* testimonials
* case studies
* metrics
* customer logos
* guarantees
* demonstrations

Avoid:

* fake credibility
* unsupported claims

---

# CTA Design

Primary CTA should have:

* clear purpose
* strong visibility
* consistent placement

Secondary actions should not compete.

---

# Responsive Landing Page Design

## Mobile

Prioritize:

* message clarity
* CTA accessibility
* fast scanning

---

## Desktop

Use:

* stronger visual storytelling
* wider layouts
* richer demonstrations

---

# Performance Requirements

Optimize:

* images
* animations
* fonts
* scripts

Landing pages must load quickly because first impressions happen immediately.

---

# Accessibility Requirements

Ensure:

* readable text
* sufficient contrast
* keyboard navigation
* semantic structure
* accessible media

---

# Conversion Review

Evaluate:

## Attention

Does the page communicate value quickly?

---

## Understanding

Can visitors explain the offering?

---

## Confidence

Does the page reduce hesitation?

---

## Action

Is the next step obvious?

---

# Landing Page Anti-Patterns

Reject:

* unclear messaging
* too many CTAs
* excessive animation
* generic copy
* weak hierarchy
* hidden value proposition
* unnecessary sections

---

# Landing Page Quality Checklist

```text id="n7m3qa"
✓ Audience is clear

✓ Value proposition is obvious

✓ Hero communicates quickly

✓ CTA is focused

✓ Trust is established

✓ Sections flow logically

✓ Mobile experience works

✓ Accessibility is supported

✓ Performance is optimized
```

---

# Final Instruction

Create landing pages that guide users from curiosity to confidence.

Do not design pages that simply look impressive.

Design experiences that help the right people understand, trust, and act.
