# Agency Website Design Prompt
**Version:** 1.0  
**Status:** Production Agency Experience Design Prompt  
**Depends On:** Product Classifier, Landing Page Intelligence, Content Intelligence, Portfolio, Accessibility Intelligence

---

# Purpose

This prompt defines the process for designing production-quality agency websites using the Design OS framework.

An agency website is not a digital brochure.

It is a strategic product designed to:

- establish credibility
- communicate expertise
- demonstrate capability
- convert qualified visitors into opportunities

---

# Design Mission

```
Understand Target Clients

↓

Define Positioning

↓

Build Trust Architecture

↓

Show Capability

↓

Create Conversion Paths

↓

Validate Client Confidence
```

---

# Before Designing

## Target Audience

Ideal clients, industries, buyer motivations, objections, decision criteria.

## Business Positioning

What the agency does, why it is different, outcomes it creates, why clients should trust it.

Avoid generic service lists and unclear positioning.

---

# Agency Principles

## Sell Outcomes, Not Services

Weak:

```
We build websites.
```

Better:

```
We create digital systems that help businesses attract customers and operate better.
```

## One Primary Conversion

Secondary actions may inform. They must not compete with the primary ask.

## Honesty

No fake logos, invented client counts, or unverifiable ROI claims.

---

# Website Architecture

```
Hero

↓

Positioning

↓

Problems We Solve

↓

Services

↓

Process

↓

Portfolio / Case Studies

↓

Proof

↓

About

↓

FAQ

↓

Contact
```

Remove sections that do not advance trust or conversion for the chosen audience.

---

# Hero Section

Must communicate who you help, what you create, and why trust you.

Brand-first: agency name is a hero-level signal. Headline must not erase brand identity.

---

# Services And Case Studies

Organize services around client needs. Each service explains problem → solution → outcome.

Portfolio demonstrates thinking, not only visuals. Case studies follow challenge → strategy → execution → outcome.

---

# Trust Architecture

Testimonials, client results, demonstrations, process transparency, expertise signals.

Avoid exaggerated claims and fake proof.

---

# Conversion Design

Define clear actions: request consultation, start project discussion, view portfolio, book discovery call.

Decision criterion: one primary CTA label across the site family, with contextual secondary actions only.

---

# Interactive Experience

Live demos and prototypes may demonstrate capability. Reject empty visual effects.

---

# Mobile, Performance, Accessibility

Prioritize positioning, navigation, portfolio browsing, and contact actions on mobile.

Optimize portfolio media. Ensure readable typography, contrast, keyboard navigation, accessible media, and semantic structure.

---

# Decision Criteria

Approve when:

- Positioning is specific enough that a wrong-fit visitor self-selects out
- Services describe outcomes
- Proof is real
- Conversion path is singular and obvious
- Mobile contact path works in under three taps from any major page

---

# Anti-Patterns

Reject:

- “We do everything” positioning
- screenshot galleries without outcomes
- competing CTAs of equal weight
- stock testimonials without attribution rules
- dark patterns in contact forms
- agency sites indistinguishable after removing the logo

---

# Agency Website Output

Example:

```
Audience

Local SMBs needing operational software

Positioning

Business systems for operators who outgrew spreadsheets

Primary CTA

Book discovery call

Services Framed As Outcomes

Get paid faster / Reduce no-shows / See orders in one place

Proof

3 named case studies with permissioned quotes

Mobile

Sticky Book call action; portfolio images deferred

Honesty

No “500+ clients” without source

Review

Pass
```

---

# Failure Conditions

Fails when:

- Positioning is generic
- Trust relies on unverifiable claims
- Visitors cannot find how to start
- Portfolio does not support the service promise

---

# Quality Checklist

```
✓ Positioning is clear
✓ Audience is understood
✓ Services communicate value
✓ Portfolio builds trust
✓ CTAs are focused
✓ Mobile experience works
✓ Performance is optimized
✓ Accessibility is supported
✓ Website feels premium without dishonest theater
```

---

# Review Questions

- Would the ideal client recognize themselves in the hero?
- Is the primary CTA unmistakable?
- Does proof survive scrutiny?
- Does mobile conversion work without desktop hover tricks?

---

# Final Instruction

Create agency websites that prove capability before a conversation begins.

Do not create pages that only describe services. Create experiences that make potential clients think: this team understands my problem and can solve it.
