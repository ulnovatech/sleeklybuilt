# Typography Intelligence
**Version:** 1.0  
**Status:** Intelligence Layer  
**Depends On:** Product Classifier, Font Intelligence, Design Constitution

---

# Purpose

Typography Intelligence transforms a chosen font into a complete typography strategy.

Choosing **Inter** or **Manrope** is only the beginning.

Typography Intelligence determines:

- hierarchy
- rhythm
- scale
- readability
- density
- scanning speed
- visual balance
- cognitive load

Typography is the framework that organizes information.

Without it, interfaces become visually noisy and difficult to use.

---

# Core Philosophy

Good typography is invisible.

Users should never admire the font.

They should effortlessly understand the interface.

Typography exists to reduce thinking.

---

# Design Priorities

Typography should optimize for:

1. Readability
2. Hierarchy
3. Scannability
4. Consistency
5. Density
6. Personality

Never reverse this order.

---

# Typography Pipeline

Every project follows this sequence:

```
Product Classification
        ↓
Font Selection
        ↓
Content Analysis
        ↓
Reading Behavior
        ↓
Hierarchy Design
        ↓
Type Scale
        ↓
Responsive Scale
        ↓
Accessibility Review
```

---

# Step 1 — Analyze Content

Determine what dominates the interface.

Possible content types:

- Headlines
- Forms
- Dashboards
- Documentation
- Data Tables
- Product Listings
- Marketing Copy
- Messaging
- Navigation

Typography should adapt to the dominant content.

---

# Step 2 — Reading Pattern

Determine how users consume information.

Examples:

Quick scanning

Decision making

Continuous reading

Data comparison

Task execution

Each pattern requires a different hierarchy.

---

# Step 3 — Information Density

Low Density

Large typography

More whitespace

Relaxed rhythm

---

Medium Density

Balanced typography

Balanced spacing

---

High Density

Smaller but readable typography

Efficient hierarchy

Compact spacing

Never sacrifice readability.

Display

1.15–1.3

1.5–1.7

Long-form reading

---

# Line Length

Ideal reading width:

45–75 characters

Marketing copy may extend slightly.

Documentation should remain within comfortable limits.

---

# Paragraph Spacing

Paragraph spacing should exceed line spacing.

Paragraphs should be visually distinct without appearing disconnected.

---

# Text Alignment

Default:

Left aligned

Center alignment only for:

- Hero sections
- Empty states
- Success screens

Avoid justified text.

---

# Numbers

For financial and analytical interfaces:

Use tabular figures whenever available.

This improves comparison.

---

# Data Tables

Typography should prioritize scanning.

Use:

- consistent weights
- restrained emphasis
- clear hierarchy

Avoid excessive bold text.

---

# Forms

Labels should remain visible.

Placeholder text should never replace labels.

Input typography should prioritize clarity.

---

# Navigation

Navigation typography should be concise.

Avoid oversized navigation labels.

Maintain consistency across all destinations.

---

# Buttons

Button text should:

Be concise

Use sentence case

Remain highly readable

Avoid excessive capitalization.

---

# Capitalization

Preferred:

Sentence Case

Section Titles

Proper Names

Avoid ALL CAPS except:

- tiny overlines
- compact labels
- special metadata

---

# Contrast

Hierarchy should rely primarily on:

Size

Weight

Spacing

Then color.

Never depend solely on lighter gray text.

---

# Responsive Typography

Typography should adapt gradually.

Never dramatically shrink headings.

Instead:

Adjust layout before reducing readability.

---

# Dark Mode

Increase perceived readability.

Avoid:

Low-contrast body text

Thin font weights

Overly subtle hierarchy

---

# Accessibility

Typography must support:

- browser zoom
- system scaling
- large accessibility text
- reduced visual acuity

Readable typography always wins.

---

# Common Mistakes

Avoid:

- Random font sizes
- Multiple font families
- Tiny captions
- Giant headings without hierarchy
- Dense paragraphs
- Overuse of bold
- Decorative typography
- Inconsistent spacing

# Review Questions

Before approving typography, ask:

- Can users scan this quickly?
- Is the hierarchy immediately obvious?
- Is body text effortless to read?
- Are headings proportional?
- Is spacing creating rhythm?
- Is typography doing more work than color?
- Can information density increase without breaking readability?

If any answer is "No",

refine the typography.

---

# Final Rule

Typography should guide the user's eyes so naturally that they never think about reading.

They simply understand.

That is the hallmark of world-class interface typography.
