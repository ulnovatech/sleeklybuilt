# Color Intelligence
**Version:** 1.0  
**Status:** Intelligence Layer  
**Depends On:** Product Classifier, Visual Language, Accessibility

---

# Purpose

Color Intelligence determines the complete color strategy of a product.

Color is not decoration.

Color communicates:

- identity
- emotion
- hierarchy
- actions
- status
- trust

A poor color system makes a product feel amateur.

A disciplined color system makes a product feel intentional.

---

# Core Philosophy

Never choose colors because they look attractive individually.

Choose colors because they create:

- clarity
- emotional alignment
- usability
- accessibility
- consistency

Color follows strategy.

# Color System Structure

Every product should define:

## Brand Colors

Primary identity colors.

Used for:

- key actions
- brand moments
- emphasis

---

## Neutral Colors

Foundation colors.

Used for:

- backgrounds
- surfaces
- text
- borders

Most of the interface should use neutrals.

---

## Semantic Colors

Communicate states.

Required:

Success

Warning

Error

Information

---

## Interactive Colors

Define:

- hover
- active
- focus
- disabled

---

# 60-30-10 Principle

Recommended balance:

60%

Neutral foundation

30%

Supporting colors

10%

Accent colors

Avoid making every element colorful.

---

# Primary Color Rules

Primary color should:

- represent the brand
- support accessibility
- work on light backgrounds
- work on dark backgrounds
- remain recognizable

Never use a primary color that fails readability.

---

# Accent Color Rules

Accent colors are powerful.

Use sparingly.

Accent should highlight:

- important actions
- key information
- meaningful moments

Do not color every component.

---

# Neutral System

A professional product requires a strong neutral palette.

Include:

Background

Surface

Elevated Surface

Border

Primary Text

Secondary Text

Muted Text

Disabled Text

---

# Dark Mode

Dark mode is not inverted colors.

It requires:

- adjusted contrast
- softer whites
- controlled brightness
- proper elevation

Avoid pure black backgrounds unless intentional.

---

# Gradients

Gradients are allowed only when they serve:

- branding
- emphasis
- atmosphere

Never use gradients to hide weak design.

Avoid:

- random rainbow gradients
- excessive background effects
- decorative noise

---

# Glass Effects

Glassmorphism should be rare.

Use only when:

- context supports it
- readability remains excellent
- performance is acceptable

Never sacrifice clarity.

---

# Color Accessibility

Every color system must consider:

- contrast ratio
- color blindness
- dark mode
- text readability
- state recognition

Never communicate meaning through color alone.

---

# Status Colors

Status colors must remain consistent.

Example:

Success

Green family

Warning

Amber family

Error

Red family

Information

Blue family

Do not redefine meanings randomly.

---

# Color and Typography Relationship

Color should support typography.

Never use color to compensate for weak hierarchy.

Correct order:

Typography

↓

Spacing

↓

Contrast

↓

Color

---

# Component Color Rules

Buttons:

Primary action

Highest emphasis

Secondary action

Reduced emphasis

Danger action

Clear warning

Cards:

Mostly neutral

Avoid colorful cards everywhere.

---

# Data Visualization

Charts require careful color logic.

Rules:

- prioritize readability
- avoid unnecessary colors
- support color blindness
- maintain consistency

Do not create rainbow dashboards.

# Failure Conditions

Color selection fails when:

- Too many colors exist.
- Every component is highlighted.
- Accessibility fails.
- Colors have no meaning.
- Trends override usability.
- Gradients replace hierarchy.
- Brand personality is unclear.

---

# Review Questions

Before approval:

- Does color communicate meaning?
- Is hierarchy clear without color?
- Are actions obvious?
- Does the palette feel intentional?
- Does it support accessibility?
- Does it age well?
- Would removing colors improve clarity?

---

# Final Rule

Great color systems are quiet.

They guide attention.

They build trust.

They support the experience without competing with it.

The best interface colors are not the ones users notice.

They are the ones that make everything feel correct.
